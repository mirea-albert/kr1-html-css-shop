# CyberGear — Магазин игровой периферии (kr1-html-css-shop)

Учебный проект интернет-магазина профессиональной игровой периферии, созданный в рамках дисциплины «Фронтенд и бэкенд разработка».

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».
В проекте реализован полноценный многостраничный HTML/CSS-сайт соревновательной игровой периферии с единой навигацией, каталогом, фильтрами, таблицей характеристик, модальным окном и оформлением заказа.

## О проекте
Сайт представляет собой витрину магазина игровой периферии с промо-блоком, преимуществами, каталогом товаров и формой оформления заявки. В проекте реализована клиентская валидация форм, управление состояниями элементов интерфейса и структурированная система стилей на основе CSS-переменных и методологии БЭМ.

## Структура проекта
- `index.html` — главная страница (hero-блок, преимущества, популярные товары, модальное окно заявки);
- `catalog.html` — каталог товаров с боковой панелью фильтров и сеткой товаров;
- `product.html` — страница карточки товара с технической таблицей характеристик;
- `order.html` — страница полноценного оформления заказа;
- `contacts.html` — контакты шоурума и форма связи;
- `css/style.css` — файл стилей (дизайн-токены, Flexbox, Grid, БЭМ, состояния, позиционирование);
- `js/main.js` — файл JavaScript (управление `<dialog>` и валидация форм);
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Дополнительные элементы

## Реализованная функциональность
1. **Семантическая разметка:** логическая структура документа с использованием тегов `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<dialog>`, `<footer>`.
2. **Многостраничность и навигация:** единое навигационное меню, связывающее страницы между собой, а также якорные ссылки для быстрого перемещения по секциям главной страницы.
3. **Хлебные крошки:** вспомогательная навигационная цепочка на внутренних страницах (`catalog.html`, `product.html`, `order.html`, `contacts.html`).
4. **Модальное окно:** нативный HTML5-элемент `<dialog>` с формой заказа, открывающийся по кнопкам с автоподстановкой товара.
5. **Валидация формы:** клиентская проверка обязательных полей средствами JavaScript с выводом сообщений об ошибках и успехе.
6. **Дизайн-система на CSS-переменных:** централизованное управление палитрой, отступами, скруглениями и типографикой через `:root`.
7. **Flexbox и CSS Grid:** адаптивная раскладка навигации через Flexbox и двумерные сетки карточек и каталога (`grid-template-areas`).
8. **Методология БЭМ:** строгое разделение на блоки, элементы и модификаторы (`product-card--featured`, `button--primary` и др.).
9. **Позиционирование элементов:** демонстрация `relative`, `absolute` (бейджи скидок/новинок), `sticky` (фильтр в каталоге), `fixed` (кнопка «Наверх») и `z-index`.
10. **Таблицы данных:** структурированная таблица технических параметров (`<caption>`, `<thead>`, `<tbody>`, `<th>`, `<td>`).

## БЭМ-структура проекта
В проекте используются следующие БЭМ-блоки:
- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — промо-блок;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (`product-card--featured`, `product-card--discount`);
- `catalog-layout` — структура каталога;
- `catalog-filters` — боковой фильтр;
- `product-detail` — блок детального описания товара;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заказа;
- `button` — кнопка (`button--primary`, `button--secondary`);
- `site-footer` — подвал сайта.
